## Abstract summary
The paper describes an IoT-based drainage monitoring system intended to identify drainage water-level changes and hazardous gases. It describes a NodeMCU ESP8266, ultrasonic and MQ-135 gas sensing, a 16×2 LCD, a buzzer, and the Blynk IoT platform. Sensor data is processed by the NodeMCU and sent over Wi-Fi for remote monitoring; the LCD provides local status information, while buzzer and mobile notifications are described as alert mechanisms.

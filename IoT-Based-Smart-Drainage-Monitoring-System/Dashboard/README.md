# Smart Drainage Monitoring Dashboard

## IoT-Based Smart Drainage Monitoring System with Alert Messages

### Dashboard Overview

The web-based dashboard provides a centralized interface to monitor drainage conditions. It displays sensor readings, water-level conditions, drainage status, and alert notifications.

### Dashboard Features

- **Water Level Monitoring:** Displays the measured water level.
- **Drainage Status:** Shows Normal, Warning, or Critical status.
- **Blockage Detection:** Indicates possible drainage blockage.
- **Alert Notifications:** Displays warnings when abnormal conditions are detected.
- **Real-Time Monitoring:** Updates dashboard information using incoming sensor data.
- **Remote Access:** Allows users to monitor drainage conditions through a web interface.

### Dashboard Status Indicators

| Status | Description |
|---|---|
| 🟢 NORMAL | Drainage operating normally |
| 🟡 WARNING | Water level is increasing |
| 🔴 CRITICAL | Critical water level or blockage detected |

# Results and Output

## IoT-Based Smart Drainage Monitoring System with Alert Messages

### 1. Project Results

The developed IoT-based Smart Drainage Monitoring System successfully demonstrates real-time drainage monitoring using sensors and an alert mechanism. The system is designed to identify abnormal drainage conditions and notify the responsible person to enable timely action.

### 2. Observed Outputs

- **Real-Time Monitoring:** Continuously monitors drainage conditions using connected sensors.
- **Alert Notifications:** Generates alerts when abnormal conditions are detected.
- **Dashboard Monitoring:** Displays sensor readings and system status through a web-based dashboard.
- **Early Detection:** Helps identify potential drainage blockages and overflow situations.
- **Remote Accessibility:** Allows users to monitor drainage conditions remotely through the dashboard.

### 3. Dashboard Results

The web dashboard provides a centralized interface for monitoring the drainage system.

Key dashboard features:
- Live sensor status.
- Drainage condition monitoring.
- Warning and alert indicators.
- System status visualization.
- Historical monitoring information (when data logging is enabled).

### 4. Expected System Behavior

| Condition | System Response |
|---|---|
| Normal drainage | Displays normal status |
| Water level increases | Updates sensor readings |
| Drainage blockage detected | Generates warning |
| Critical water level | Triggers alert notification |
| System returns to normal | Updates dashboard status |

### 5. Project Outcome

The project demonstrates how IoT technology can be used to improve drainage monitoring and help reduce the risks associated with water overflow and drainage blockage.

The proposed system provides an affordable and scalable approach to smart drainage management and can be further developed for municipal drainage networks and smart city applications.

### 6. Conclusion

The IoT-Based Smart Drainage Monitoring System with Alert Messages provides a practical approach to real-time drainage monitoring. By integrating sensors, a microcontroller, IoT connectivity, alert notifications, and a monitoring dashboard, the project demonstrates the potential of automated drainage management.
